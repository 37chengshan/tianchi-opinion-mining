# 0.7162 Anchor → 0.80 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以线上已验证的 `candidate-f9eac4b6d4ea-b384f88e9621`（LB=0.7162020541）为唯一主干，保留其 one-stage span-relation 归纳偏置，通过安全修复、OpinioNet-style 结构增强、强中文 encoder、TAPT、5-fold 概率级 ensemble 与 Qwen verifier/RAG，分阶段冲击线上 0.80。

**Architecture:** 主线不再使用 dense Grid V2。先冻结并复现历史 RBT3 5-fold champion，再只做 isolated ablation；只有验证有效的修复才能合并进 Anchor V1。随后保持同一 one-stage head，切换 WWM/RoBERTa/ERNIE 类 encoder；finalists 进入 5-fold、score-level ensemble。Qwen 只负责 implicit/long-tail/冲突样本的 verifier/challenger，不允许直接覆盖高置信 Anchor。

**Tech Stack:** Python 3.12, PyTorch, Hugging Face Transformers, MPS, hfl/rbt3, hfl/chinese-roberta-wwm-ext, hfl/chinese-bert-wwm-ext/compatible ERNIE, MLX/MLX-LM for Qwen3-4B, existing ResourceGuard/Dashboard/strict F1 evaluator.

**Spec:** `docs/superpowers/plans/2026-09-28-anchor-to-0.8-plan.md`

## Global Constraints

- Hardware: Apple M1 Pro, 16GB unified memory；训练进程以 memory pressure / available memory 为最终约束，正常目标 8–10GB，可短时到 12GB，但不得长期挤压系统。
- Official online champion: `candidate-f9eac4b6d4ea-b384f88e9621`, LB=0.7162020541；任何实验失败不得覆盖它。
- Champion local source: `artifacts/experiments/neural_5fold_confirm`, local strict OOF F1=0.7208976157082748, P=0.7458884231, R=0.6975271411。
- Champion architecture: `hfl/rbt3` + one-stage span/relation, 5-fold, 4 epochs/fold, max_length=96, batch=4, grad_accum=2, trainable_layers=2, relation_top_k=2。
- 所有新实验必须使用固定 folds、strict quadruple metric、完整 OOF candidate map 和独立 test candidate map。
- Local OOF 与 leaderboard 必须分栏记录，不得再混为同一分数。
- 不允许 seed sweep、连续阈值暴搜、无证据更换主结构、把 Grid V2 恢复为主线。
- 任何一次结构改动只允许改变一个主变量；没有 isolated evidence 不得合并。
- 外部无标注/伪标签数据只有在当前赛规明确允许后才能加入正式训练。
- 线上提交只用于验证离线已证明的 candidate，不用于搜索超参数。

## Review Focus

1. Champion 是否可由历史 5-fold checkpoint 重新生成完全相同的 `Result.csv`；不能则禁止继续新训练。
2. official offsets 在重复 surface term 时是否严格使用标注 occurrence，而不是 `.find()` 第一次出现。
3. `Aspect="_"`、`Opinion="_"`、dual implicit 是否 train/decode round-trip 一致。
4. 同一 span 上多个四元组是否会被 target overwrite 或 decoder/NMS 错删。
5. score-level ensemble 是否使用 fold-safe OOF 学习，不得在同一 OOF 上调参后自评。

## Resource Policy for M1 Pro 16GB

- ResourceGuard checks at step granularity.
- GREEN: continue current batch/layers.
- YELLOW: stop increasing memory; next fold may reduce batch or trainable layers.
- RED: save emergency checkpoint, terminate current fold safely, clear cache, restart fold with reduced config.
- Never mutate optimizer trainable parameter set halfway through an epoch.
- Do not run Qwen training concurrently with encoder training.
- Qwen3-4B 4-bit preferred locally; Qwen3-8B only if quantized route is demonstrably stable or remote compute is intentionally used.

---

## Stop Conditions

Immediately stop a branch when any of these holds:

1. Same-fold ablation loses >0.005 F1 and does not repair a critical correctness bug.
2. Strong encoder remains <0.735 after the one planned config; no LR/seed sweep.
3. TAPT gain <0.004.
4. Ensemble gain <0.004 over best single.
5. Qwen verifier complete-OOF gain <0.003.
6. Local→online ordering reverses for two consecutive well-controlled candidates; pause uploads and audit distribution/calibration before continuing.
7. Any candidate changes explicit text away from the exact source substring.

## Final Success Criteria

The project is considered complete when:

- the 0.7162 champion remains reproducible and archived;
- all retained fixes have isolated evidence;
- at least one finalist has trustworthy 5-fold OOF and test candidates;
- ensemble/Qwen stages are used only if their gates pass;
- final submission is fully validated and recorded in the manifest;
- target is Online F1 0.80+, but no stage is allowed to claim or fabricate that outcome before leaderboard evidence exists.
