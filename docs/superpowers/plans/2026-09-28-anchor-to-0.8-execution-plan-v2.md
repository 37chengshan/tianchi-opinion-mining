## Statistical promotion rule

Every candidate report must contain:

- pooled strict micro P/R/F1;
- per-fold P/R/F1 and delta vs parent;
- TP/FP/FN delta;
- error-bucket delta;
- paired review-level bootstrap F1 delta, 2000 resamples, fixed seed;
- candidate count and oracle recall.

Default keep rule for a normal ablation:

1. trusted F1 delta meets the task-specific minimum; and
2. bootstrap 90% interval is not materially negative; and
3. at least 4/5 folds non-negative for 5-fold confirmation, or all 3 screening folds are inspected for catastrophic regression.

Correctness fixes may be retained in a challenger even with total delta down to -0.001, but they must never replace the immutable online champion until the combined challenger proves improvement.

## Compute budget discipline

Use fold-epochs rather than open-ended wall-clock searching:

- correctness ablation: one fixed 3-fold profile each;
- same-head backbone: one primary profile, at most one predeclared refinement if near/promising;
- targeted head change: one 3-fold run each, stop on negative evidence;
- only finalists receive 5-fold confirmation;
- Qwen full cross-fit only after complementarity pilot passes.

No branch gets repeated seeds merely to rescue a weak result.

## Error-budget milestones

Do not judge only by total F1. Track whether the main bottlenecks move:

- implicit-A FN: 1218 → desired sustained reduction without proportional FP growth;
- span/unseen-opinion FP: 1136 → desired sustained reduction without large recall loss;
- wrong class FP: 259 — secondary priority;
- wrong pair FP: 181 — secondary priority unless strong encoder changes its share.

A promising route toward 0.8 should recover **hundreds** of correct quadruples and/or remove **hundreds** of false positives. Small fixes are useful but cannot be mistaken for the whole solution.

## Model-selection order after V2 review

`Artifact/schema freeze → Trusted evaluator → B1/B2/B3 → Same-head strong encoder → Implicit/boundary targeted head ablations → Official-only segmentation/TAPT if positive → EMA/FGM/SWA if positive → 5-fold finalists → Complementarity/calibration → Qwen pilot/full verifier → Optional compliant pseudo-label → Online`.

## Stop conditions

Stop a branch when any applies:

1. correctness-neutral model change loses >0.005 trusted F1;
2. strong encoder primary + allowed refinement remains below parent and lacks complementarity;
3. target-head ablation fails to improve its intended error bucket;
4. augmentation/TAPT < +0.004;
5. stability trick < +0.002 or bootstrap suggests noise;
6. ensemble union oracle lacks headroom or actual gain < +0.004;
7. Qwen full OOF gain < +0.003;
8. resource downshift creates mixed effective configs across folds;
9. any explicit output is not an exact source substring;
10. external-data legality is not explicitly verified.
