# 天池评论观点挖掘：0.7162 Anchor → 0.80 执行计划

## 0. 已验证基线

- Online champion: `candidate-f9eac4b6d4ea-b384f88e9621`, LB = **0.7162020541**.
- Local source: `neural_5fold_confirm`, strict OOF F1 = **0.7208976157**, P = 0.745888, R = 0.697527.
- Architecture: `hfl/rbt3` + one-stage span/relation, 5-fold, 4 epochs/fold, joint Category×Polarity class, relation_top_k=2.
- Error profile: TP=4626, FP=1576, FN=2006; FN implicit-A=1218; FP span/unseen-opinion=1136.
- Current Grid/WWM/MacBERT route is not the mainline because its local/LB evidence is weaker than this anchor.

## 1. Research conclusions to adopt

### Same-origin OpinioNet Top3

- One-stage end-to-end extraction/classification rather than a two-stage chain.
- Joint modeling of Aspect start/end, Opinion start/end, objectness, Category and Polarity.
- 5-fold CV.
- Domain adaptation before downstream fine-tuning.
- Heterogeneous Chinese encoders (RoBERTa-WWM / BERT-WWM / ERNIE).
- Probability/candidate-score averaging across folds/models, then NMS/thresholding.
- Historical scores show single-model CV near 0.79 and multi-model ensemble above 0.82 in the same competition family.
- Blind data augmentation is not mandatory; their augmentation variant slightly underperformed their best ensemble.

### Current Tianchi forum

- Strong BERT route: end-to-end + joint Category/Polarity label, strong Chinese encoders, EMA/SWA/FGM/PGD, pseudo labels and selective augmentation.
- LLM route: Qwen2.5/Qwen3 fine-tuning can match or exceed complicated BERT pipelines on this small dataset.
- A forum solution explicitly reports Qwen3-8B full-tune + LoRA fusion Score 0.81.
- RAG route: BM25 Top20 -> semantic reranker Top5 -> few-shot labeled examples, especially useful for implicit aspects, long-tail cases and Category/Polarity ambiguity.

## 2. Frozen execution order

`Anchor freeze/reproduction -> safe anchor ablations -> OpinioNet-style same-head challengers -> official-data TAPT -> 5-fold finalists -> probability ensemble -> Qwen verifier/challenger -> optional legal pseudo-label -> online validation`

Do not return to dense Grid as the mainline. Do not seed-sweep or leaderboard-threshold-sweep.

## Phase B — Three isolated safety ablations on the anchor

Each change is evaluated alone on the same fixed 3-fold split first. No bundled rewrite.

### B1 official offsets only

- Explicit A/O use official start/end offsets.
- Repeated surface text must preserve the annotated occurrence.
- Keep head, loss, decoder and thresholds unchanged.

### B2 implicit-O only

- Preserve the existing CLS/sentinel mechanism.
- Add full train/decode round-trip for `OpinionTerm="_"`.
- Track the known 172 implicit-O gold labels separately.

### B3 multi-relation only

- Preserve multiple quadruples sharing an aspect/opinion span.
- Prevent last-label overwrite while leaving span proposal logic unchanged.

**Keep rule:** strict 3-fold F1 >= anchor same-fold +0.004, or a major target-bucket recall gain with total F1 loss <=0.001. Otherwise revert that change.

## Phase C — OpinioNet-style one-stage head challenger

Do not use dense all-pair grid. Keep the anchor's compact one-stage bias and make it closer to the historical Top3 structure:

- token/object anchor score;
- Aspect start pointer + end pointer;
- Opinion start pointer + end pointer;
- joint 39-way Category×Polarity head;
- confidence = pointer terms × objectness × class confidence;
- constrained beam search for legal spans;
- overlap-aware NMS;
- explicit implicit sentinel.

Train RBT3 first as a control. Only when this head matches/beats the anchor do we swap encoder.

**Gate:** RBT3 control must not be materially worse than the historical anchor under the same validation protocol.

## Phase D — Strong encoders, identical head

Use exactly the same one-stage head/folds/decoder/loss. Change only encoder:

1. `hfl/chinese-roberta-wwm-ext`
2. `hfl/chinese-bert-wwm-ext` or a compatible ERNIE checkpoint
3. MacBERT only as a third complementary challenger if resources permit

M1 Pro 16GB policy:

- base-size encoders first, not large;
- train top 2–4 encoder layers initially;
- batch 2–4 with gradient accumulation;
- length 96/112 unless data proves truncation;
- dynamic resource guard remains mandatory.

**Gate:** 3-fold strict F1 >=0.735 to justify 5-fold; >=0.75 gets highest priority.

## Phase E — Official-data TAPT / domain adaptation

1. Start with official train reviews only: short MLM/TAPT continuation.
2. Prefer the OpinioNet-inspired dual-task idea if cheap: alternate MLM adaptation and supervised downstream batches.
3. External unlabeled review data is blocked until current competition rules explicitly permit it.
4. One adaptation schedule per finalist; no epoch sweep.

**Gate:** >= +0.004 strict 3-fold F1 over the same encoder without TAPT.

## Phase F — Stability tricks, one at a time

Order: EMA -> FGM -> SWA. PGD only if FGM shows real gain.

- one change per ablation;
- no simultaneous LR/epoch/head changes;
- no seed sweep.

**Keep rule:** >= +0.002 strict F1.

## Phase G — 5-fold finalists + score-level ensemble

At most three finalists:

- RBT3 anchor family;
- best WWM/RoBERTa/ERNIE challenger;
- one complementary encoder/LLM challenger.

Requirements:

- save raw candidate scores for every fold/test sample;
- ensemble scores/probabilities, not final CSV hard voting;
- consensus items get lower acceptance threshold;
- single-model-only items require higher confidence;
- all ensemble weights selected fold-safely from a small discrete set.

**Milestones:**

- best single 5-fold local target: >=0.76;
- encoder ensemble target: >=0.78;
- only after >=0.78 do we spend serious time on Qwen/RAG for the final 0.8 push.

## Phase H — Qwen challenger/verifier for the final push

Local hardware route:

- first attempt `Qwen3-4B` 4-bit MLX/QLoRA;
- do not attempt 32B locally;
- Qwen3-8B only if an efficient quantized/remote training route is available without destabilizing the main pipeline.

Training/output:

- strict JSON schema;
- explicit A/O must be exact substrings;
- implicit is represented by `_`;
- Category and Polarity constrained to legal enums;
- no free-text explanation.

RAG:

- BM25 retrieve Top20 from training fold;
- rerank to Top5;
- feed labeled few-shot examples;
- fold-safe retrieval during OOF.

Primary use cases:

- implicit-A / implicit-O;
- model disagreement cases;
- long-tail categories;
- Category/Polarity ambiguity.

Do not let Qwen blindly delete high-confidence anchor predictions. Use it as a conflict resolver, verifier or high-confidence missing-quadruple proposer.

**Gate:** complete OOF >= +0.003, not just a curated hard subset.

## Phase I — Pseudo-labeling only if rules explicitly permit it
